Shockwave is a memory-safe hierarchical planner for hybrid-parallel Transformer training. It combines memory-feasible parallel configuration search, sensitivity-guided configuration selection, and pipeline-stage layer partitioning to generate an efficient training plan for a target model and GPU cluster.

The implementation is available in the <a href="https://github.com/zuoyanzhang/Shockwave">Shockwave GitHub repository</a>. The accompanying paper, <a href="https://doi.org/10.1145/3842760">Memory-Safe Hierarchical Planning for Hybrid-Parallel Transformer Training</a>, was published in ACM Transactions on Architecture and Code Optimization.
